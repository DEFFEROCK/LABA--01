## Схема работы калькулятора:
**1) Токенизация (`tokenizastion`) - разбивает исходную строку на символы и собирает все в один массив**

**2) Валидация (`validate_tokenization`) - делает проверку исходного выржения на арифмитическую корректность**

**3) Унарность (`_unar`) - знак в начале выражения или перед операндом "приклеивается" к нему**

**4) Обратная Польская Запись(RPN) (`to_rpn`) - переводить выражения в RPN**

**5) Находим значение выражения в RPN(`solution`) - получаем резлуьтат выражения RPN**

## Схема работы конвертера:
**1) Проверка частей (`check_part`) - проверяет из какой та или иная единица измерения**

**2) Валидация (`validation`) - делает проверку ввода на корректность**

**3) Конвертер (`_converter`) - функция принимает на вход значение и две единицы измерения(из какой -> в какую перевести), на выходе полуаем `float`**

# Поддерживается:

`Calculator` - вычисляет значение выражения, операнды `+ - * /` и приоритет `*`,`/` надо другими операндами. Учтены унарные знаки
`+`, `-`.

`Converter` - перевод между единицами измерения, находящихся в одной части:
* `kg` и `g`               # масса - weight
* `mm`, `cm`, `m` и `km`   # длина - height
* `c`, `f`, `k`            # температура - temperature

# Использование через терминал:

`python -m toolkit --help`

`python -m toolkit calc "EXPRESSION"`

`python -m toolkit convert VALUE --from UNIT --to UNIT`

# Тесты через терминал:
**Калькулятор:**
<pre>
python -m toolkit calc "7.0*6" -> 42.0
python -m toolkit calc "1+-3" -> -2.0
python -m toolkit calc "7/0" -> Деление на ноль запрещено
python -m toolkit calc "2 * -3" -> -6
</pre>

**Конвертер:**
<pre>
python -m toolkit convert 5 --from "kg" --to "g" -> 5000.0
python -m toolkit convert -10 --from "k" --to "c" -> температура не можеть быть ниже абсолютного нуля
python -m toolkit convert 6000.0 --from "mm" --to "f" -> единицы измерения находятся в разных частях
python -m toolkit convert 150 --from "c" --to "k" -> 423.15
</pre>


# Функционал:
* Вычисление значения выражений, в которых есть операнды `+, -, *, /`, установлены приоритеты знаков, выстроена работа унарных знаков `+` и `-`.
* Конвертер между величинами, которые находятся в одной части единиц измерения: `масса - weight`, `длина - lenght`,`температура - temperature`.
* На ввод в конверте можно подать название единицы измерения в любом формате, важно, чтобы она существовала, например: `Kg` будет считатя как `kg`. 
* То же самое и с пробелами, в калькуляторе и конвертере они не влияют на получение результата и на его значение.
* Работа с терминалом и вывод ответов или ошибок.
